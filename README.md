# Fuzzy DID Experiments

Experimental framework for stable binary face template generation,
Fuzzy Extractor key reconstruction, and DID authentication evaluation.

## Environment

- Python 3.10 or 3.11

## Installation

### MacOS, Linux

```bash
python -m venv .venv
source .venv/bin/activate

pip install -e ".[dev]"
```

### Winodws PowerShell

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1

pip install -e ".[dev]"
```
